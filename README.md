# 古诗文默写

高中语文五册课本里的古诗文，做成一个能离线用的默写本。

课文、注释、难字全是从人教版教科书 PDF 里抽出来的，一字不改：**66 篇古诗文**
（课本要求背诵的 20 篇）、**3030 条课本注释**、**510 个难字**。

---

## 一、怎么用

三个文件放在**同一个目录**里，双击 `index.html` 就能用，断网也行。

| 文件 | 内容 | 谁来改 |
|---|---|---|
| `index.html` | 程序本体 | 一般不动 |
| `data.js` | 正文、难字、注释、理解性默写、译文解析 | 由 `tools/` 生成，但难字可以手圈，见第四节 |
| `user.js` | 你的标记和错题 | 页面导出，你替换 |

**手机上打开显示「没读到 data.js」**，是因为安卓某些文件管理器给的不是正常本地路径。
在电脑上跑一次 `python3 merge.py`，它把三个文件并成一个 `古诗文默写_单文件.html`，
把那一个文件拷到手机上即可。改完 `data.js` 之后重跑一次就行。

---

## 二、六种模式

**句子默写**　挖掉句子里的小句，画横线。看答案时除了本句，还会把**本段原文**整段
显示出来，本句在段落里标红，方便靠上下文回忆。

**难字默写**　只挖被标为难字的单个字，画小方框。看答案时难字标红加虚线底，
课本注过音的把拼音一并给出。范围自动限定在含难字的句子。

**注释**　给一个例句，其中一个词带角标，问这个词在这里作什么讲。课本来源的释义用
正体显示，补充和实词手册的用楷体，并带来源标签。

**词语**　看拼音写词语（字生僻的）／看词写拼音（有字变了读音的）。词都在这五本
课本里出现过，优先挑含生僻字和会读错的。每题标着来源：**课本注音**最可靠，
其次是**成语**，**常用词**来自词典，留个心眼。

**理解性默写**　给提示语，填出对应的句子。

**看原文**　仿课本版式：整篇按段排下来，被注的词带角标，注释跟在每段后面，
要背的段落左边一道朱线。顶上有「只看白文」的开关，关了注释就能自测。
不要求背的篇目也在这儿——它们不出默写题，只供查阅。

答错的题如果在 `gloss` 里有对应的译文解析，会先弹出一页强化，看完再进下一题。
答对不打扰。

## 三、页面上的东西

### 篇目

点「篇目」弹出一块面板，按册分成五组，一行一个复选框。行末标着课本的要求：
**背诵** / **部分背诵**（如《师说》只背第 1 段）/ **不背**。

面板顶上能搜篇名，也能「整册全选」「只要背诵的」。收起来之后，按钮旁边那行字
告诉你选了什么。

### 出题参数

都是独立的，可以任意组合。

- **顺序**　按原文，或者打乱。
- **题量**　全部，或者抽 10 / 20 / 30 / 50 题。
- **挖空量**　每题一处 / 挖去一半 / 尽量多挖。单题最多挖 6 处，再长的句子也不会
  变成满屏横线。
- **筛选**　不筛选 / 只含难字的 / 只练标记过的 / 只练错过的。

键盘：空格看答案，1 是「我记得」，2 是「我不记得」，复习页空格继续。

### 挑出记不住的那几处

一句话挖了五个空，你可能只有最后一个想不起来。所以点「我不记得」之前，
**答案里标红的地方都能点**——点一下标成「不会」，再点取消，旁边有「全选」。

一处都不点就是整句都不会。点过的会记下来，以后用**「筛选 → 只练错过的」**，
这些题**只挖你挑过的那几处**，不再满题挖空。

### 互补默写

一轮做完，结束页有个「互补再默一遍」：把这一轮挖过的地方变成提示、原来给的提示
挖成空。两轮合起来，这些句子每个字都默过一遍。

### 标记和错题

每题右上角有个星号，点一下标记。答错的题下面有「把这些全标记上」。

**想看都标了什么、错过什么**，点「我的数据」——标记过的题和答错过的题都列在那儿，
带篇名和句子，答错的还标着错了几次、挑出了几处记不住。可以逐条移出，
也可以一键「只练这些」。

标记是**按句子内容**存的，不是按题号，所以往 `data.js` 中间插内容不会让标记错位。

### 存档

「我的数据」里还有：

- **下载 user.js**　把下载到的文件替换掉目录里那个旧的。
- **导入框里的内容**　整段 `user.js` 或者里面那个大括号都认。
- **清空**　清掉全部标记、错题和挑出来的空。

平时的答题痕迹存在浏览器自己的存储里，随时可用。`user.js` 是存档点，不是实时
数据库，网页没有权限往本地文件里写东西。所以换设备之前记得导一次。

## 四、难字怎么改

**直接在 `data.js` 的 corpus 里给字加大括号就行**，像在纸书上圈错字一样：

```
艰难苦恨繁霜鬓，{潦}倒新停浊酒杯。
```

想去掉就把括号删了。圈过的字自动进难字表，**一篇里圈一处，这一篇里这个字就都算
难字**，一个字不用圈第二遍。

重跑 `tools/build.py` **不会冲掉你圈的**——它会先把你加的、删的读出来，记进
`tools/hardchars.tsv` 这本账，再原样带回生成结果。那张表能一眼看出你加了哪些字、
又把哪些自动判定的字去掉了。

改完记得跑一次 `python3 merge.py`，不然手机上的单文件版还是旧的。

## 五、data.js 的六个板块

`data.js` 是 `tools/` 从课本 PDF 生成的。除了上面说的加减大括号，其余内容
**别手改**——改了会在下次重跑时丢掉。要改内容就改 `extract/篇/` 下的中间稿
或者 `tools/` 里的表，怎么改见第六节。

格式说明各板块上方都写着，这里是要点。竖线是半角 `|`，字段前后的空格会被自动去掉。

### 1. corpus　正文

```
# 篇名 | 作者 | 诗 | 背
正文第一行
正文第二行

正文第三行（空行之后算新的一段）
```

- 第三项填 `诗` 或 `文`。
- 第四项是**背诵范围**，照课本的「学习提示」填：`背` 全篇要背；`背1` 只背第 1 段
  （课本写「背诵《师说》的第1段」）；`不背` 不要求背，只进「看原文」和「注释」。
  不写第四项就当成要背。
- `// 册 必修上` 这样的注释行是分组标记，篇目面板按它分组。
- **空行分段**。看答案时显示的就是这个段。
- 段内：`诗` 每行一题；`文` 按句号问号叹号分题，**不足十个字的并进下一题**
  （「求！尔何如？」这种短句单独成题没意思）。
- 逗号、分号切出挖空的最小单位。**顿号不切**。
- 难字用大括号圈起来，见第四节。
- 以 `//` 开头的行会被忽略。

### 2. hardChars　难字表

两类字都在这儿，空格分隔：

- **难读的**——课本给了注音的，写成 `衿(jīn)` `匝(zā)`，括号里的音会在看答案时给出。
- **难写的**——字形生僻的，单写一个字。判据是《通用规范汉字表》一级字表：
  古诗文正文里不在那 3500 常用字内的，就算难写。比数字频准——「樽」「衿」
  「掇」「觥」在课本里出现七八次，按字频不算低，可都是二级（次常用）字，
  确实容易写错；反过来「俭」「偿」「剖」「堤」在课本里也只出现几次，
  却都是一级常用字，不该当难写字考。

和正文里圈过的字取并集。

### 3. notes　注释

```
来源 | 字词 | 释义 | 例句 | 出处
```

- **来源**填三种之一：`课本`（视为准确，正体显示）、`补充`（学校补充，楷体+标签）、
  `实词`（实词手册，楷体+标签）。
- **例句**里把被考的那个词用大括号圈起来，页面会给它加角标。
- **出处**如果是库里已有的篇名，这条归那一篇管，跟着篇目筛选走；如果不在库里
  （实词手册的外篇例句），则任何时候都会出。
- 课本的长注释里常套着小注（〔青青子衿，悠悠我心〕……衿，衣服的交领。），
  入库时主条目和小注**各占一条**，这样单个字也考得到。「看原文」里只显示主条目，
  跟课本一个样。

### 4. words　词语

```
词 | 拼音 | 题型 | 来源
```

- **题型**：`写` 看拼音写词语、`读` 看词写拼音、`都考` 两种都出。
- **来源**：`课本`（课本自己注的音，最权威）、`成语`、`词典`。
- 由 `tools/words.py` 生成，见第六节。

### 5. comprehension　理解性默写

```
篇名 | 提示语 | 答案
```

篇名要和 `corpus` 里一字不差。**这一板块课本里没有现成内容，待补。**

### 6. gloss　译文与解析

```
出处 | 原句 | 译文与解析
```

- **原句**要和 `corpus` 里切出的那一题一字不差，程序靠它对应。
- 第三段里想分行，用两个斜杠 `//` 隔开。
- 只在答错时出现。**这一板块课本里没有现成内容，待补。**

## 六、data.js 是怎么来的

不是手写的，是从五本课本 PDF 里抽出来的。三步：

```
python3 tools/pdfdump.py     # 按字体切版面，每页一份 JSON  → extract/raw/
python3 tools/assemble.py    # 按篇合并，解析背诵要求       → extract/篇/
python3 tools/words.py       # 抽词语表                    → extract/词语.tsv
python3 tools/build.py       # 生成 data.js
python3 merge.py             # 并成手机用的单文件
```

| 文件 | 做什么 |
|---|---|
| `tools/pieces.tsv` | 人工圈定的 66 篇古诗文：册、起始页、篇名、作者、体裁 |
| `tools/glyphs.tsv` | 补字表。课本里十来个生僻字排版时是画上去的，PDF 文本层根本没有这个字，按位置补回来 |
| `tools/hardchars.tsv` | 你手圈的难字账本，由 `build.py` 自动维护 |
| `tools/data/常用字-一级3500.txt` | 《通用规范汉字表》一级字表。**难字就按它判**：古诗文正文里不在这 3500 常用字内的，算难写 |
| `tools/data/成语表.tsv`、`词语表.tsv` | 第三方词典的词和拼音，只作「哪些算词、标准怎么读」的依据 |
| `extract/篇/*.md` | 每篇一份中间稿：正文（带 `⟦n⟧` 角标）、注释、学习提示、体检结果。人工校对看这个 |

**背诵与否**不是手填的，是从课文后面的「学习提示」里解析出来的。课本一共七八种
写法（`背诵课文。` `背诵《短歌行》。` `背诵课文《劝学》全篇和《师说》的第1段。`
`背诵《离骚》（节选）第3段。`），都认。

**两道自检**，跑脚本时会自己报出来：

- 每篇正文里的角标数必须和课本注释条数一样，对不上就是版面读错了。
- 每条注释的词条都要能在正文里找到——课本注了什么，正文就得有什么。这道关口最灵，
  《劝学》的「輮以为轮」、《庖丁解牛》的「而况大軱乎」都是这么查出来的。

踩过的坑和每一轮改了什么，记在 [PROGRESS.md](PROGRESS.md)。

## 七、已知的限制

- 长句子一题最多挖 6 处，觉得不够可以改 `index.html` 里的 `pickBlanks`。
- 分题粒度：诗按行，文按句号（不足十字并进下一题，阈值在 `index.html` 的 `MIN_CHARS`）。
- 难字是按「篇 + 字」记的，同一篇里圈一处等于整篇都圈，不能只圈某一处。
- `user.js` 只能靠导出和替换来同步，页面无法自己写回文件。
- 理解性默写和译文解析两个板块还是空的。
- 苹果手机上打开本地 HTML 限制较多，安卓正常。
