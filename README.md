# 学科复习

碎片时间拿手机练。一套离线可用的网页，按科目分模块，每个模块一个引擎。

**从 v0.24 起这个仓库不只装语文了**——原先它是「古诗文默写」，只有语文一科；
现在外面套了一层科目选择壳，语文收进 `chinese/`，数学新建在 `math/`，
英语物理化学生物留了位置。本文件是总入口，各模块的详细说明在各自目录里。

---

## 零、怎么用

双击根目录的 **`index.html`**，选一科进去。断网也能用。

```
index.html          ← 从这里进
chinese/            语文模块（原来的古诗文默写，整个搬过来的）
math/               数学模块（新建）
```

手机上如果提示读不到数据文件，是某些安卓文件管理器给的不是正常本地路径，
在电脑上跑一次 `python3 chinese/merge.py`，把生成的 `chinese/dist/` 里那个单文件版拷过去用。
（上线之后就不用这一招了，直接开网址——见第三点五节。）

## 一、语文工作模块 `chinese/`

**已建成，六种模式全可用。** 高中五册课本里的古诗文默写本。

课文、注释、难字全是从人教版教科书 PDF 里抽出来的，一字不改：**66 篇古诗文**
（课本要求背诵的 20 篇）、**3031 条课本注释**、**579 个难字**，另有 **1320 个词语**，
每个词都带释义和例句。

| 模式 | 干什么 |
|---|---|
| 句子默写 | 挖掉句子里的小句画横线，看答案时连整段原文一起给，本句标红 |
| 难字默写 | 只挖被标为难字的单个字，课本注过音的把拼音一并给出 |
| 注释 | 给例句，其中一个词带角标，问它在这儿作什么讲 |
| 理解性默写 | 给提示语填句子（板块待补） |
| 词语 | 看拼音写词语 / 看词写拼音，都带例句情景和释义 |
| 看原文 | 仿课本版式整篇排下来，注释可开关 |

**特点**：答对不打扰；答错能挑出「具体哪几处记不住」，以后只挖那几处；
一轮做完可以「互补再默一遍」，把挖过的变提示、提示变挖空。

**语料是生成的**，由 `chinese/tools/` 从五本课本 PDF 抽出来，别手改 `data.js`
（唯一的例外是在正文里加减大括号圈难字，重跑脚本不会冲掉）。

→ **详见 [`chinese/README.md`](chinese/README.md)**，以及
[`chinese/data_structure.md`](chinese/data_structure.md)（语料格式）、
[`chinese/html_structure.md`](chinese/html_structure.md)（页面程序）、
[`chinese/extract_pdf_method.md`](chinese/extract_pdf_method.md)（PDF 解析踩过的坑）。

## 二、数学工作模块 `math/`

**v0.25 新建，骨架已通，十个大类里建好了两个。**

和语文最根本的区别：**这里没有题库**。数学题是模板反复构造出来的，
所以题目**现场生成、算出答案、不重样**，只有错题需要存。

**十个大类、86 个细类，全部建成**（`math/engine.js` 里登记）：

| 大类 | 细类数 | 内容 |
|---|---|---|
| 数字计算 | 17 | 千以内加减、混合运算、平方立方、两位数乘法、多项累加、分数↔小数、质因数分解、最大公约数/最小公倍数、阶乘、分母有理化、根式化简，外加乘 11 / 乘 25 / 十位同个位补十 / 平方差凑整四种速算技巧 |
| 三角计算 | 12 | 特殊角求值、诱导公式、和差角、二倍角、三倍角、降幂升幂、积化和差、和差化积、万能公式、辅助角、正余弦定理、反三角函数值 |
| 向量计算 | 7 | 坐标运算、数量积、模长、平行垂直判定、夹角余弦、投影、三点共线与基本定理 |
| 立体与平面几何 | 9 | 球/柱/锥/台的表面积体积、圆锥母线、三角形面积五种算法、外接圆内切圆、扇形、长方体对角线与外接球、正四面体的二级结论 |
| 解析几何 | 9 | 两点距离、点到直线距离、斜率与倾斜角、圆的方程、椭圆、双曲线、抛物线、中点弦与焦点弦（二级结论）、两直线位置关系 |
| 方程与不等式 | 9 | 二次方程求根、韦达、判别式、因式分解、一元二次不等式、均值不等式、指数运算律、对数运算律与换底、对数求值 |
| 复数计算 | 6 | 乘法、除法（分母实数化）、模、共轭、i 的幂次循环、几何意义 |
| 导数计算 | 5 | 基本导数表、求导法则、多项式求导、切线斜率、单调性与极值 |
| 概率统计 | 6 | 排列数、组合数、组合性质与二项式定理、古典概型、二项分布期望方差、正态分布 3σ |
| 数列 | 6 | 等差通项与求和、等比通项与求和、常用求和公式、中项裂项与常用手法 |

**公式怎么排的**：用 **KaTeX**（v0.16.47），文件放在仓库 `vendor/katex/` 里，
**不联网、断网照排**。连 **mhchem 扩展**也一并带上了，所以**化学方程式现在就能排**——
配平系数、电荷上标、反应条件、↑↓、可逆双箭头都支持：

```
\ce{2H2 + O2 ->[点燃] 2H2O}
\ce{N2 + 3H2 <=>[催化剂][高温高压] 2NH3}
```

**v0.33 起所有公式都过 KaTeX。** 此前只有显式调用 `F.*` 的地方才排版，
直接拼字符串的题面（`"√112 = ?"`）会漏掉——86 个细类里漏了 77 个。
现在引擎出口有一道自动排版：按中文切段，非中文段里含数学记号的整段交给 KaTeX。

**题库里的内容没有改成 LaTeX。** `engine.js` 里的 `F.*` 零件负责翻译：
细类里写的还是 `F.frac("x²", 169)`，`F.*` 把 Unicode 上下标、`<sup>` 标签
转成 TeX 再交给 KaTeX。所以 86 个细类**一个字都没动**。

**代价**：KaTeX 本体 + mhchem + 20 个字体合计 **576 KB**，
站点从 0.96 MB 变成 **1.56 MB**。全部进 Service Worker 预缓存，装到手机上后断网可用。

**「算」和「背」混在一起，引擎不区分**——两位数乘法是算，三倍角公式是背，
出题、看答案、自评的流程一模一样。**二级结论不单开大类**，散进各自所属的大类
（三角里的 sin⁴α+cos⁴α、tanA+tanB+tanC 就是），将来想专练再加筛选。

**怎么判对错：看答案后自己判，分三档**——`算对了` / `算错了` / `没算出来`。
不做输入判分，因为手机上根式、复数、向量根本打不出来。判「算错了」时
可以**顺手填一句自己算成了几**（可选，不填也能过），复盘时看得见错在哪儿。

**计时两层**：每题用了多久（卡住说明这题有问题）、全轮总时长和平均每题。

**不做弱项归纳，只记错题。** 错题攒在「我的错题」里，能「只练这些」，
能导出 `math_user.js` 换设备。

→ **详见 [`math/engine_structure.md`](math/engine_structure.md)**（引擎怎么组织的、怎么加细类）。

## 三点五、装到手机上 / 上线（PWA）

从 **v0.26** 起，这套东西是一个 **PWA**——用网址打开之后可以「添加到主屏幕」，
之后就像个 App 一样点开，**断网照样用，有新版本会自己提示更新**。

### 现在就能用的两种方式

| 怎么用 | 要什么 | 更新怎么办 |
|---|---|---|
| **双击本地文件** | 什么都不要 | 我改完你重新拉一份 |
| **PWA（推荐）** | 一个 https 网址 | **自动**——我推新版，你下次打开就有，不用重装 |

PWA 的关键零件在仓库根目录：`manifest.webmanifest`（装机信息）、`sw.js`（离线缓存和
更新）、`pwa.js`（注册 + 弹更新提示）、`icons/`（图标）。
**双击本地文件打开时这套东西会静默跳过**，页面照常工作，不受影响。

### 上线：GitHub Pages（使用者已定）

**使用者决定把仓库设为公开，走 GitHub Pages。** 步骤：

1. 仓库 **Settings → General → 最底下 Danger Zone → Change visibility → 改成 Public**
2. 把开发分支合进 `main`（`pages.yml` 监听的是 `main` 的推送）
3. **Settings → Pages → Source 选「GitHub Actions」**
4. 等 Actions 跑完，网址是 `https://wabulae1225.github.io/Guwen_recite/`

手机浏览器打开这个网址 → 安卓会弹「装上」，iOS 走「共享 → 添加到主屏幕」。
装好之后**断网能用，我推新版你下次打开就有**，不用再拷副本。

**发布的内容**由 `.github/workflows/pages.yml` 挑：根目录的科目壳和 PWA 四件套、
`chinese/{index.html,data.js,user.js}`、`math/`，**不含**
`chinese/textbooks/`（五本教材 PDF）、`tools/`、`extract/`、`dist/`。
产物约 1 MB，另带 `robots.txt` 不让搜索引擎收录。

> **记录一下公开意味着什么**（使用者已知情并决定照做）：公开仓库等于公开全部 git 历史，
> 所以 `chinese/textbooks/` 里那五本人教版教科书 PDF、以及一字不改抄下来的
> `chinese/data.js`，**在仓库里是可被公开访问的**——发布配置只管网页产物，管不着仓库本身。
> 不想这样的话有两条别的路：改写历史剔除 PDF（会把所有 commit 号换掉，`LOG.md` 里的
> 引用会失效），或者仓库保持私有、改用 Cloudflare Pages 部署。**当前选择是直接公开。**

### 改完代码记得

`sw.js` 顶上有个 `VERSION`，**改完代码把它加一**，否则浏览器可能还在用旧缓存。
