# README

## 一、文件怎么放

三个文件必须放在**同一个目录**里：

| 文件 | 内容 | 谁来改 |
|---|---|---|
| `index.html` | 程序本体 | 一般不动 |
| `data.js` | 正文、难字表、注释、理解性默写、译文解析 | **由 `tools/` 从课本 PDF 生成，别手改** |
| `user.js` | 标记和错题次数 | 页面导出，你替换 |

打开 `index.html` 就能用。断网可用。

如果页面打开后显示「没读到 data.js」，说明浏览器拿到的不是正常的本地路径（安卓某些文件管理器会这样）。这时在电脑上跑一次 `merge.py`，它会把三个文件并成一个 `古诗文默写_单文件.html`，把那一个文件拷到手机上即可。

```
python3 merge.py
```

改完 `data.js` 之后重跑一次就行。

## 二、五种模式

**句子默写**　挖掉句子里的小句，画横线。看答案时除了本句，还会把**本段原文**整段显示出来，本句在段落里标红，方便靠上下文回忆。

**难字默写**　只挖被标为难字的单个字，画小方框。看答案时难字标红加虚线底。范围自动限定在含难字的句子。

**注释**　给一个例句，其中一个字带角标，问这个字在这里作什么讲。课本来源的释义用正体显示，补充和实词手册的用楷体，并带来源标签。

**理解性默写**　给提示语，填出对应的句子。

**看原文**　仿课本版式，整篇按段排下来，被注的词带角标，注释跟在每段后面，
要背的段落左边有一道朱线。顶上有个「只看白文」的开关，关了注释就能自测。
不要求背的篇目也在这儿，它们不出默写题，只供查阅。

答错的题（点了「我不记得」）如果在 `gloss` 里有对应的译文解析，会先弹出一页强化，看完再进下一题。答对不打扰。

## 三、参数

都是独立的，可以任意组合。

- **篇目**　按册分五行，点一下切换。点最左边的册名可以整册全选／全不选。
  颜色深的是课本要求背诵的，浅的不要求背——后者不出默写题，只进「看原文」和「注释」。
- **顺序**　按原文，或者打乱。
- **题量**　全部，或者抽 10 / 20 / 30 / 50 题。
- **挖空量**　每题一处 / 挖去一半 / 尽量多挖。单题最多挖 6 处，再长的句子也不会变成满屏横线。
- **筛选**　不筛选 / 只含难字的 / 只练标记过的 / 只练错过的。

键盘：空格看答案，1 是「我记得」，2 是「我不记得」，复习页空格继续。

## 四、标记和数据

每题右上角有个星号，点一下标记。答错的题下面有「把这些全标记上」。

标记是**按句子内容**存的，不是按题号，所以往 `data.js` 中间插内容不会让标记错位。

点「我的数据」：

- **下载 user.js**　把下载到的文件替换掉目录里那个旧的。
- **导入框里的内容**　整段 `user.js` 或者里面那个大括号都认。
- **清空**　清掉全部标记和错题次数。

平时的答题痕迹存在浏览器自己的存储里，随时可用。`user.js` 是存档点，不是实时数据库，网页没有权限往本地文件里写东西。所以换设备之前记得导一次。

## 五、data.js 的五个板块

批量生成时照这份格式写。竖线是半角 `|`，字段前后的空格会被自动去掉。

### 1. corpus　正文

```
# 篇名 | 作者 | 诗 | 背
正文第一行
正文第二行

正文第三行（空行之后算新的一段）

# 另一篇 | 作者 | 文
整段文字写成一行……
```

- 第三项填 `诗` 或 `文`。
- 第四项是**背诵范围**，照课本的「学习提示」填：
  `背` 全篇要背；`背1` 只背第 1 段（课本写「背诵《师说》的第1段」）；
  `不背` 不要求背，只进「看原文」和「注释」，不出默写题。
  不写第四项就当成要背，旧的三项写法照样能用。
- `// 册 必修上` 这样的注释行是分组标记，篇目选择区按它分行。
- **空行分段**。看答案时显示的就是这个段。
- 段内：`诗` 每行一题；`文` 按句号问号叹号分题，**不足十个字的并进下一题**
  （「求！尔何如？」这种短句单独成题没意思）。
- 课本里有些段落极短（《侍坐》的「夫子哂之。」「“求！尔何如？”」各自成段），
  生成时会把不足六个字的段并进下一段。门槛压得比分题的十字低——段落是课本
  分的，能不动就不动，《劝学》的「君子曰：学不可以已。」八个字也是一段，
  独立成题不算短，就没并走。
- 逗号、分号切出挖空的最小单位。**顿号不切**。
- 难写的字用大括号圈起来：`契阔谈{䜩}`、`{觥}筹交错`。圈过的字自动进难字表，全库通用，一个字只需圈一次。
- 以 `//` 开头的行会被忽略，可以当注释用。
- 一篇如果没有正文（只有篇头），会被自动跳过，不显示在篇目里。

### 2. hardChars　难字表

两类字都在这儿：

- **难读的**——课本给了注音的，写成 `衿(jīn)` `匝(zā)`，括号里的音会在看答案时一并给出。
- **难写的**——字形生僻的，单写一个字就行。

空格分隔。和正文里圈过的字取并集。

### 3. notes　注释

```
来源 | 字词 | 释义 | 例句 | 出处
```

- **来源**填三种之一：`课本`（视为准确，正体显示）、`补充`（学校补充，楷体+标签）、`实词`（实词手册，楷体+标签）。
- 课本的长注释里常常套着小注（〔青青子衿，悠悠我心〕……衿，衣服的交领。），
  入库时主条目和小注**各占一条**，这样单个字也考得到。「看原文」里只显示主条目，
  跟课本一个样。
- **例句**里把被考的那个字用大括号圈起来，页面会给它加角标。
- 一题只问一个字。同一个字有几个义项就写几条，各带各的例句，不要合并。
- **出处**如果是库里已有的篇名，这条注释归那一篇管，跟着篇目筛选走；如果出处不在库里（实词手册里的外篇例句），则任何时候都会出。

例：

```
课本 | 受 | 同「授」，传授 | 师者，所以传道{受}业解惑也 | 师说
实词 | 爱 | 爱惜，吝惜 | 向使三国各{爱}其地 | 六国论
实词 | 爱 | 喜爱，喜好 | 秦{爱}纷奢，人亦念其家 | 阿房宫赋
```

### 4. comprehension　理解性默写

```
篇名 | 提示语 | 答案
```

篇名要和 `corpus` 里的篇名一字不差。

### 5. gloss　译文与解析

```
出处 | 原句 | 译文与解析
```

- **原句**要和 `corpus` 里切出来的那一题一字不差，程序靠它对应。所谓一题，`诗` 是一行，`文` 是一个句号单位。
- 第三段里想分行，用两个斜杠 `//` 隔开。
- 只在答错时出现。没写的题不影响使用。

## 六、已知的限制

- 长句子一题最多挖 6 处，觉得不够可以改。
- 分题粒度：诗按行，文按句号（不足十字的并进下一题，这个阈值在 `index.html` 的 `MIN_CHARS`）。
- `user.js` 只能靠导出和替换来同步，页面无法自己写回文件。
- 苹果手机上打开本地 HTML 限制较多，安卓正常。

## 七、data.js 是怎么来的

`data.js` 不是手写的，是从五本课本 PDF 里抽出来的。要改内容，改 `tools/` 下的表
或者 `extract/篇/` 里的中间稿，再把三步跑一遍：

```
python3 tools/pdfdump.py     # 按字体切版面，每页一份 JSON  → extract/raw/
python3 tools/assemble.py    # 按篇合并，解析背诵要求       → extract/篇/
python3 tools/build.py       # 生成 data.js
```

| 文件 | 做什么 |
|---|---|
| `tools/pieces.tsv` | 人工圈定的 66 篇古诗文：册、起始页、篇名、作者、体裁 |
| `tools/glyphs.tsv` | 补字表。课本里十来个生僻字（輮、薆、騞、駃騠……）排版时是画上去的，PDF 文本层根本没有这个字，按位置补回来 |
| `extract/篇/*.md` | 每篇一份中间稿：正文（带 `⟦n⟧` 角标）、注释、学习提示、体检结果。人工校对看这个 |

**背诵与否**不是手填的，是从课文后面的「学习提示」里解析出来的。课本一共七八种写法
（`背诵课文。` `背诵《短歌行》。` `背诵课文《劝学》全篇和《师说》的第1段。`
`背诵《离骚》（节选）第3段。`），都认。

**两道自检**，跑脚本时会自己报出来：

- 每篇正文里的角标数必须和课本注释条数一样，对不上就是版面读错了。
- 每条注释的词条都要能在正文里找到——课本注了什么，正文就得有什么。
  这道关口最灵，《劝学》的「輮以为轮」、《庖丁解牛》的「而况大軱乎」
  都是这么查出来的：字在行首行尾掉了，两字之间没有空当，别的办法发现不了。
