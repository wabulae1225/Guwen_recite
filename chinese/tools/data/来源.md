# 外来参考资料的来源

这个目录放**第三方的字表词表**，只作判据和释义来源，不直接进 `data.js`。
收进题库的词还得在五本课本语料里出现过（规矩见 `tools/words.py` 开头）。

`.tsv` 的来源写在各自文件开头的 `#` 注释里；JSON 放不下注释，所以记在这份。

| 文件 | 来源 | 用途 |
|---|---|---|
| `常用字-一级3500.txt` | 《通用规范汉字表》一级字表，国务院 2013-06-05 发布 | **难写字的判据**：正文里不在这 3500 字内的算难写 |
| `成语表.tsv` | [chinese-xinhua](https://github.com/pwxcoo/chinese-xinhua)（经 [hanzi-words](https://github.com/zispace/hanzi-words) 整理） | 哪些算成语、标准怎么读 |
| `词语表.tsv` | [chinese-dictionary](https://github.com/mapull/chinese-dictionary)（同上整理），原表三十多万条，只留课本用到的 | 词的边界；注音一律和 pypinyin 交叉验证 |
| `成语释义.json` | [chinese-xinhua](https://github.com/pwxcoo/chinese-xinhua) `data/idiom.json`，30895 条 | 成语的释义、**出处**（`derivation`）、例句（`example`） |
| `新华词语.json` | [chinese-xinhua](https://github.com/pwxcoo/chinese-xinhua) `data/ci.json`，264434 条 | 词语释义（只有释义，没有例句） |

两份 JSON 是 v0.21 加的，**原样存下来**（36 MB）——使用者的要求是「下载一下免得以后找不到」。
日常跑脚本不必读全量：`words.py` 抽出这 1320 个词要用的那部分，落进 `data.js` 的 `words` 板块。

## 这两本词典的已知毛病（用之前先知道）

`chinese-xinhua` 这套数据是从纸书 OCR 整理来的，有几类固定残缺，`words.py` 里有对应的清洗：

1. **开引号被吃掉**——「即骆驼”其奇畜则橐驼。」原本该是「即骆驼，“其奇畜则橐驼”」一类。
2. **释义带 `1.` `2.` 序号**，义项之间用 `\n` 或半角分号隔开。
3. **成语例句里混着 `★`（出处分隔）和 `～`（代指成语本身）**，没有例句的写作「无」。
4. 释义常给**古义**，不一定贴课本语境——所以课本自己的注释永远排在它前面。

所以它们的可靠性排在课本注释之后。采信顺序：
**课本注释 > 课本原句 > 成语释义 > 新华词语 > 自拟**（自拟的在页面上明确标出来）。
